# LIMEN Engineering Charter

LIMEN is a Tech Sphere Challenge 2026 project.

Before changing code:

1. Preserve the modular-monolith boundaries defined in `ARCHITECTURE.md`.
2. Do not introduce vendor SDKs outside provider adapters.
3. Do not weaken `UNKNOWN` / `CONFLICTING` clinical semantics.
4. Do not allow generative output to override a stronger safety decision.
5. Do not hard-code challenge case IDs, labels, or hidden trajectory truth.
6. Do not commit secrets, `.env`, runtime databases, model weights, logs, or generated patient audio.
7. Do not claim metrics that were not generated by evaluation scripts.
8. Any change to safety, RAG deletion, voice, or telemetry requires tests.
9. Keep browser call + knowledge console functional.
10. Prefer the simplest architecture that meets the requirement.

Before finishing a task, run the relevant tests, type checks, and lint commands.
